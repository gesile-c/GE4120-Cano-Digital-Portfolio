# Activity  — Presentation Design Principles
## Overview
This activity focused on effective visual communication and the principles of presentation design. We learned how design can guide the audience's attention, improve readability, and communicate information more clearly.
## My Output
For this activity, I created a promotional poster for a free coffee event using the content and details provided by our professor.
The design applies presentation design principles such as contrast, visual hierarchy, color scheme, typography, spacing, and layout.
